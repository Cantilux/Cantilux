## 🚀 Featured

### [astrostyle](https://github.com/Cantilux/astrostyle)

<a href="https://cantilux.github.io/astrostyle/">
  <img src="https://raw.githubusercontent.com/Cantilux/astrostyle/master/.github/assets/banner.svg" alt="astrostyle: a CSS framework in the ASTROPRISMA style" width="100%">
</a>

A CSS framework dressed in the colors and attitude of the **ASTROPRISMA** tabletop RPG. Buttons, inputs, dialogs, tabs, toasts and many more components, light and dark themes, design tokens, zero dependencies. SCSS core, plain CSS build, a pinch of vanilla JavaScript.

`npm install astrostyle` · [Docs & live examples](https://cantilux.github.io/astrostyle/) · 🛰️ in development, on the road to 1.0

### [breakouts](https://github.com/Cantilux/breakouts)

A minimal SCSS/CSS layout framework: full-bleed containers, breakout columns, responsive grids and a clean set of utilities. For content that refuses to stay inside the lines.

`npm install breakouts` · [Docs](https://cantilux.github.io/breakouts/)
